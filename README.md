# Night Browser

Night Browser est un navigateur de bureau Windows conçu avec une interface nocturne et futuriste.

- [Visiter le site de présentation et télécharger Night Browser](https://jujulian1607h.github.io/nova-browser/)
- [Découvrir la version 1.0.2](https://github.com/jujulian1607h/nova-browser/releases/tag/v1.0.2)

L’installateur Windows n’est pas signé numériquement. Consultez l’avertissement de sécurité et l’empreinte SHA-256 indiquée sur la page de la version avant installation.
