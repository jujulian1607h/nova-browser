# Night Browser

Night Browser 1.0.2 est un navigateur de bureau Windows construit avec Electron, avec une interface futuriste pensée pour une navigation fluide.

## Télécharger

Téléchargez [`Night-Browser-Setup-1.0.2.exe`](https://github.com/jujulian1607h/nova-browser/releases/download/v1.0.2/Night-Browser-Setup-1.0.2.exe) depuis la [Release 1.0.2](https://github.com/jujulian1607h/nova-browser/releases/tag/v1.0.2).

> **Avis de sécurité :** l’installateur n’est pas signé numériquement. Windows ne peut pas vérifier l’identité de son éditeur à partir d’une signature. Aucune certification ni aucun audit de sécurité n’est revendiqué.

## Vérifier le téléchargement

SHA-256 :

```text
8DE28A6092F164CDF2E3DEB7A57B926328ED48E13A0BA249E975269A218CAEC3
```

Dans PowerShell :

```powershell
Get-FileHash ".\Night-Browser-Setup-1.0.2.exe" -Algorithm SHA256
```
