# Night Browser

Night Browser est un navigateur de bureau Windows avec onglets, historique local, gestionnaire de téléchargements intégré et une interface compacte.

- [Site de présentation et téléchargement](https://jujulian1607h.github.io/nova-browser/)
- [Télécharger la version 1.0.4](https://github.com/jujulian1607h/nova-browser/releases/tag/v1.0.4)
- [Code source de l’application](https://github.com/jujulian1607h/nova-browser/tree/main/app)

L’installateur Windows n’est pas signé numériquement. Consultez l’avertissement et l’empreinte SHA-256 de la Release avant installation.
