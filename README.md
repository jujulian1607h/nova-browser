# Night Browser

Night Browser est un navigateur de bureau pour Windows et Linux, avec onglets, historique local et gestionnaire de téléchargements.

- [Site de présentation : téléchargement adapté à Windows ou Linux](https://jujulian1607h.github.io/nova-browser/)
- [Release Night Browser 1.0.5](https://github.com/jujulian1607h/nova-browser/releases/tag/v1.0.5)
- [Code source](https://github.com/jujulian1607h/nova-browser/tree/main/app)

La version Linux fournit une AppImage et un paquet Debian/Ubuntu x86_64. Les installateurs ne sont pas signés numériquement ; vérifiez leur empreinte SHA-256 sur la page de la version avant installation.
