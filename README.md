# Night Browser

Night Browser est un navigateur de bureau Windows au design nocturne, avec onglets, favoris locaux, onglets privés et historique consultable.

## Télécharger la version 1.0.3

[Site de présentation](https://jujulian1607h.github.io/nova-browser/) · [Release GitHub 1.0.3](https://github.com/jujulian1607h/nova-browser/releases/tag/v1.0.3) · [Installateur Windows 64 bits](https://github.com/jujulian1607h/nova-browser/releases/download/v1.0.3/Night-Browser-Setup-1.0.3.exe)

L'historique conserve localement les 1 000 visites récentes et exclut les onglets privés. Il peut être effacé depuis l'application.
